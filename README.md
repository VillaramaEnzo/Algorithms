# Algorithms

A personal collection of algorithm practice and experiments. This repository is not meant as a library or production code — it’s a place to implement, tweak, and visualise classic algorithms for learning and play.

You’ll find implementations and small projects around **sorting**, **pathfinding**, **maze generation**, and related topics, often with simple visualisations to see how they behave. Feel free to browse or reuse anything here for your own practice.

## Structure

- **Sorting Algorithms** — Implementations and visualisers (e.g. Python, JavaScript).
- **Search Algorithms** — Pathfinding and maze-generation demos (e.g. Dijkstra, A*, BFS, DFS) with a small visualiser app.

No guarantees on performance or API stability; this is a sandbox for trying things out.
